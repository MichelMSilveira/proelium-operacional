# Oportunidades no celular

No mobile, os cartões priorizam oportunidade, contato/origem, situação, próxima ação e o botão do próximo passo.

Telefone, e-mail, responsável, valor e orientação completa ficam no expansor `Detalhes`. A ação `Excluir oportunidade` fica no menu `⋮`. A visualização desktop permanece completa.
